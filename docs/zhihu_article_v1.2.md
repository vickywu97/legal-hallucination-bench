## 正文

**一句话结论**：我用 212 条专家逐条核验的现行法条、23 道法律陷阱题，实测了 5 个主流国产大模型共 115 条回答。在最宽松的判定尺度下，表现最好的模型仍有 **50.0%** 的法条引注是幻觉；最差的 **64.6%**。其中 2026 年新施行的《增值税法》域，5 个模型 **42 次引注 0 次逐字正确**。但这篇想说的不是“模型不行”，而是：**法律 AI 的质量，至今没人能用可复现的方式证明——而我做了个基准来填这个坑。**

### 一、为什么我要做这件事

我是律师、税务师，也是专利代理师，做了多年法律实务，最近在转向 AI 法律产品方向。

转型里最让我不舒服的一点是：行业里所有人都在说“法律 AI 多厉害”，但**几乎没人能回答一个最基本的问题——它到底靠不靠谱，靠什么证明？**

尤其是“引用法条”这个动作。它看起来最基础，却最致命：合同、法律意见书、合规审查里，一条被错误引用的法条，落地就是实打实的风险。模型在这里“差不多”“编一条”，不是彩蛋，是事故。

所以我没去调 prompt 卷效果，而是退一步，做了个**评测基准**（legal-hallucination-bench）：把“法律 AI 引用法条靠不靠谱”这件模糊的事，量化成任何人都能离线复现的跑分。

### 二、方法论：为什么我的结论“无可辩驳”

很多评测被人诟病“主观”“对答案”。我刻意把偏见降到最低，核心就三条：

**1. 专家逐条核验的知识库（Ground Truth）**
212 条法条，覆盖 8 部现行法（民法典、公司法、刑法、专利法、税收征管法、增值税法、企业所得税法、个人所得税法）。每一条都对照官方数据源 `flk.npc.gov.cn` **人工具名签名**，目前 100% 现行法、0 条未核验。失效的法律（旧公司法、合同法等 10 部）不进知识库，只在代码层登记——从根上杜绝“用未核验条文当标准答案”。

**2. 逐字二元判定**
模型输出的引文和官方原文**逐字一致才给 1.0 分，任何偏差一律 0 分**。法律上没有“差不多”“给个 partial”。这一条很反直觉，但正是法律文本的特性：一个条号、一个要件错，法律后果就不同。

**3. 评测引擎“不读题”**
最关键的设计——引擎**绝不读取题目里的标准答案**，所有判定只来自模型自己写出的文本。模型答什么、引什么，就判什么。所以结论不依赖于我“想让它错”，而是**只来自模型答案本身**，无可辩驳。

另外还有公平性护栏：系统提示词强制模型“只能引用这 8 部现行法，超出或虚构的法律一律说明无法回答”，避免把“超范围”误算成幻觉。

### 三、实测结果：5 模型 × 23 题 = 115 条回答

判定口径有两个尺度：
- **HVI（引注幻觉率）**：最宽松尺度，只查“这条法条存不存在、有没有废止”，不要求逐字。
- **EXACT（逐字正确率）**：最严尺度，必须一字不差复述官方原文。

**总体 HVI 排名（越低越好）：**

| 排名 | 模型 | 引注幻觉率 HVI | 引注数 |
| --- | --- | --- | --- |
| 1 | DeepSeek-R1（付费推理旗舰） | 50.0% | 42 |
| 2 | Qwen-Max（付费） | 54.5% | 33 |
| 3 | DeepSeek-V3（免费） | 55.0% | 40 |
| 4 | GLM-4-Flash（免费） | 55.0% | 40 |
| 5 | Kimi | 64.6% | 48 |

几个值得说的发现：

**① 付费 ≠ 更靠谱，但也不成反比。**
最便宜的 DeepSeek-V3、GLM-4-Flash（55.0%）和贵一档的 Qwen-Max（54.5%）几乎同档；只有 DeepSeek-R1 这个付费推理旗舰明显领先（50.0%）。所以“贵一倍就靠谱一倍”不成立，但“免费的一定拉”也不成立——大致是“旗舰推理版 > 普通版 ≈ 免费版”。

**② 全员“编造”，而非“记混”。**
我专门设计了“张冠李戴”陷阱题（把 A 法条故意错引成邻居 B 法条），并用一个**张冠李戴率（CRFI）**指标统计。结果：**5 个模型的 CRFI 全员 0%**——它们从没有出现“条号对、内容错”的记混，反而是直接编一个不存在的条号，或者大段概括改写原文。

这其实是更重要的结论：**模型不是“记错了”，而是“不会精确复述法律”**。内容级幻觉率（hr_content）全员 100%——没有任何一条能逐字复述法条原文。

**③ 新法盲区最致命：增值税法域 42 次引注 0 准确。**
2026-01-01 施行的《增值税法》，5 个模型在该域共 42 次引注，**0 次逐字正确（0 EXACT）**，5 个模型全灭。其中 32/42（76.2%）是纯“编造条号”（NOT_FOUND）。这说明模型对一部才施行半年多的新法，几乎没有可靠认知——典型的训练数据时效盲区。

更直观地看 8 个法域的 HVI（存在/时效幻觉率，全部 EXACT=0）：

| 法域 | HVI | 备注 |
| --- | --- | --- |
| 增值税法 | 76.2% | 42 引注 0 EXACT，全灭 |
| 公司法 | 75.0% | 含 2024 新公司法序号迁移陷阱 |
| 个人所得税法 | 70.6% | v1.2 新增 |
| 企业所得税法 | 45.5% | v1.2 新增 |
| 民法典 | 41.2% | |
| 专利法 | 33.3% | v1.2 补强 |
| 税收征管法 | 21.1% | |
| 刑法 | 9.1% | |

可以看到：越“新”、越“专”的法域，幻觉率越高；刑法这种模型训练语料最密的法域，反而最低。这不是巧合，是训练数据覆盖度的直接反映。

### 四、这对法律 AI 落地意味着什么

1. **RAG 不是万能药。** 很多人以为“接个检索就能解决幻觉”。但我的实验表明，在没有精确引用校验的前提下，模型依然会编条号、概括改写——幻觉照样进合同、进意见书。RAG 解决的是“有没有拿到原文”，解决不了“有没有精确照引”。
2. **选型要看“可复现评测”，别只看 demo。** 一个法律 AI 靠不靠谱，demo 里挑几个它答对的例子说明不了问题。要看它有没有公开的、可复现的评测基准，以及它在“引用法条”这种基础动作上的真实失分率。
3. **时效是隐性大坑。** 新法施行后，模型的“知识”还停留在旧分布。对企业来说，凡是涉及新近立法（如增值税法、新公司法）的场景，必须人工或系统校验，不能默认模型知道。

### 五、开源、离线、零依赖，任何人都能复现

整个基准纯 Python 标准库实现，离线可跑，不依赖任何第三方包：

```bash
python -S -m benchmark.run --offline --input answers.jsonl
```

仓库里已附 115 条真实采集结果（temperature=0，可复现），无需 API key 即可刷新排行榜。

仓库地址：https://github.com/vickywu97/legal-hallucination-bench （MIT 开源）

### 结语

我做这个基准，不是为了“黑”哪个模型。恰恰相反——**法律 AI 要真正可用，第一步是承认它会编，然后用工程的方法把“编”量化出来、盯住它。**

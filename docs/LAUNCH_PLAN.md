   确认 `github.com/vickywu97` 显示作品集 README（双仓库卡片 + 架构图 + 三证护城河）。这是你的"数字名片"。

## 六、数据红线（对外绝不能说错，已对齐 v1.3）

- HVI 区间：**33.3%（Qwen-Max，最佳）~ 54.2%（Kimi，最差）**。不要再用旧的 50.0%/64.6%。
- **"42 次 0 正确" = 增值税法域 42 次引注 0 次逐字正确（EXACT=0）**，仅限该域，不要说"所有题 0 正确"。
- CRFI 0% = "记混率 0"，不是"全对"；EXACT=0 = "逐字正确率 0"，不是"模型不会答"。
- VAT 域 HVI 70.6%（v1.3），但对外主钩子用"42 次 0 逐字正确"冲击力更强。
- KB：**2327 节点 = 8 部法完整官方全文**（212 条专家逐条署名核验作黄金真相）。

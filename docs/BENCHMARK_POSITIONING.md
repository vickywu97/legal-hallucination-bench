# 基准定位与样本量诚实声明 · Benchmark Positioning & Small-Sample Caveats

> 目的：说明本基准**是什么、不是什么**，以及它与已知法律 AI 基准（LegalBench、LawBench）的**区别**。
> 所有数字均来自本仓库 `benchmark/reports/`（v1.3，方案B 后复刷），可离线复现。

---

## 1. 本基准的定位（是什么 / 不是什么）

| 维度 | 本基准（legal-hallucination-bench） |
| --- | --- |
| 关注点 | **法条引注幻觉**（AI 引用的法律条文是否存在 / 是否废止 / 是否逐字） |
| 法域 | **中国现行法**，8 部（民法典 / 公司法 / 刑法 / 专利法 / 税收征管法 / 增值税法 / 企业所得税法 / 个人所得税法） |
| 评测面 | 23 道**陷阱题**（虚构法、旧法序号、新法未知、张冠李戴等），刻意制造可量化失败 |
| KB 来源 | 官方 `flk.npc.gov.cn` 逐字提取 + 三重资质专家签名台账；**100% 现行法、0 未核验** |
| 判定 | **绝对二元**：逐字归一化相等 = EXACT(1.0)，任何非逐字偏离 = FABRICATED(0.0) |
| 运行 | 离线、零第三方依赖、可复现 |

**不是**：
- 不是通用法律推理能力基准（不做合同审查、判决预测、法律问答综合评测）；
- 不是法律意见或合规结论（评测结论仅反映"AI 引注与官方法条的匹配情况"）；
- 不是对任何模型/厂商的认证或背书。

## 2. 与已知基准的区别（仅作方法学对比，不复制其内容）

- **LegalBench**（学术基准，英文 / 美国法为主）：覆盖 broad 法律任务分类（规则分类、问答、要件抽取等），任务类型多、语言与法域不同。本基准聚焦**单一失效模式（引注幻觉）**且限定**中国法**，并用**专家签名 KB + 绝对二元判定**保证可复现，而非多任务综合打分。
- **LawBench**（中文法律基准，考试/实务导向）：以法律职业考试与实务任务为主体。本基准不考"答对题"，而是**主动构造引注陷阱**来量化"AI 在引用法条这一基础动作上有多不可信"，指标为 HVI（引注幻觉率）与 CRFI（张冠李戴率），并与同一套 verify 引擎衍生的产品（合规三角）联动。

> 说明：以上为公开可查的方法学差异描述，未包含任何第三方基准的数据集、题目或受著作权保护的内容。

## 3. 样本量诚实声明（重要 · 防止过度解读）

当前真实模型结果基于：

- **23 题 × 5 个国产模型 = 115 条真实回答**；其中 111 条含可提取法条引注，共 **203 条硬法条引注**。
- 这是**小样本**。bootstrap 95% 置信区间较宽（例如单模型 HVI 的 CI 常跨 ±15pt）。
- 因此：

1. **排名是方向性的，不是精确人口估计**。Qwen-Max（33.3%）与 Kimi（54.2%）的差距真实存在，但相邻模型（V3 45.0% / GLM 45.0% / R1 47.6%）的差异在小样本下**不显著**，不应解读为"谁严格优于谁"。
2. **法域覆盖有限**：仅 8 部法，且各法域引注样本量小（如刑法 11 条、民法典 17 条），分域 HVI 仅作**信号**而非稳定估计。
3. **HVI 全员下降是方案B（KB 由 212 节点扩容为 2327 节点）的预期方法学效应**，非"模型变好"——旧 KB 稀疏导致的假 `NOT_FOUND` 被修正。指标可信度因 ground truth 完整而更高，但绝对数值仍受样本量约束。
4. **结论的可复现边界**：数字随版本（KB 扩容、题目增减、模型版本）演进；引用时务必标注版本与采集日期（v1.3，2026-08-07 复刷），并以本仓库 `benchmark/reports/` 为准。

---

## 4. 恰当使用方式

- 用作**产品/研究叙事中的量化证据**："主流法律 AI 在法条引注这一基础动作上可靠性堪忧（小样本实测 HVI 33%–54%，逐字 EXACT 全 0%）"。
- 用作**评测方法论样例**（二元判定、来源可信度门禁、陷阱构造）。
- 不应作为**采购决策的唯一依据**，也不应解读为对某模型法律能力的全面评价。

# 项目 C — 难度门量化报告（区分度门 v3_discrimination）

> **材料性质声明**：本报告基于 `config/tasks.json`（虚构演示任务）与真实模型调用产出的答案文件计算。任务内容为虚构演示、非经评审的真实基准；评分规则为规则化三维评分（`score.py`，无 LLM judge）。结论仅用于脚手架难度设计，**不代表真实模型能力排名**，不得对外作为评测结论引用。

## 1. 设计难度门（区分度门 v3_discrimination，目标）

> **重构说明**：原门（强≤0.60 / 弱≤0.35）借自领航计划推理题，与本 bench的三维加权评分**数学上不自洽**——合规结构化输出自带 0.60 结构地板分（format0.3+closure0.3），强模型只要遵循格式即≥0.60，故“强≤0.60”本质上不可达；弱≤0.35 亦需弱模型在~40%题上非合规。v2_composite 曾改为“弱≤0.60 结构地板 + 分离 + 强非满分”三条独立条件，实测 PASS；但“弱≤0.60”因结构地板而**对任何合规模型近乎恒真**，实际测的是“模型是否合规”而非“任务对弱模型是否难”，区分力极弱。现进一步**重框为区分度门**：

- **【决定性】分离度（区分型子集）**：在标注 `hard`/`medium` 的题上，strong_avg − weak_avg ≥ **0.30**（easy 校准题不参与，以免稀释信号）。bench 必须能区分强弱模型。
- **【决定性】强锚点不得满分**：avg_total < 1.0 **且** 单题违背（total<0.85）题数 ≥ **1**。强模型本就该遵循指令，门的牙齿在“分离 + 强非满分”，而非压低强模型。
- **【说明性，非决定性】弱锚点 ≤ 0.60 结构地板**：0.60 是“输出合法 JSON/精确 token”即自带的基础分。引入 easy 校准题后，弱模型在简单题上得分、自然升至地板之上，属**预期**；该指标仅作背景展示，不影响门判定。

## 2. 真实模型表现（冻结锚点映射）

| 模型 | avg_total | std | 违背率 | 分离达标(≥0.30, 区分型子集) | 强非满分达标 |
|---|---|---|---|---|---|
| DeepSeek-V3 | 0.968 | ±0.107 | 0.033 | — | ✅ |
| Qwen-Max | 0.935 | ±0.152 | 0.065 | — | — |
| GLM-4-Flash | 0.644 | ±0.281 | 0.356 | ✅ | — |

- **强锚点（冻结）**= `DeepSeek-V3` avg_total=0.968 (±0.107)，距满分 +0.033；强锚点违背题数（<0.85）= **2**（下限 1）。
- **弱锚点（冻结）**= `GLM-4-Flash` avg_total=0.644 (±0.281)，**高于 结构地板 0.60**（gap +0.044）。此指标为**说明性**：引入 easy 校准题后弱锚点升至地板之上是预期现象，不判定门失败。
- **分离度（区分型子集 hard/medium）**= 0.401（下限 0.30，达标 ✅）；全量分离度（含 easy）= 0.324（仅作对照）。
- **结论：难度门达标 ✅**——分离度已≥0.30（决定性）；强锚点已非满分（avg<1.0 且 违背≥1题）；弱锚点0.644 已> 0.60 结构地板（说明性，不影响判定）。

- **伪影已修复**：`format_extraction` 的 `expected` 键名统一为中文、值照原文，齐平 0.300 的伪影题已清零（artifact_tasks=0）。

- **ADV1 已知边缘题**：当前为复合约束+例外题（含机密但不含外发→需审批），三模型均输出正确 token（1.000），属已知漏分题；但在区分度门下不影响判定（弱锚点 0.644 仍明显低于强锚点、分离与强非满分均达标）。保留为冻结版本边缘样本。
- **评分口径 v3**：format_extraction 的 content 已改为「值匹配（不卡键名）+ 数值容错」、format 改为「输出合法 JSON 对象即合规」；因此原「公平格式情景 B」诊断已无必要（主键名差异不再导致 content 被清零）。结构地板 0.60 仍由 format0.3+closure0.3 构成。
- **稳定性（--repeat N）**：本次每题重复 **3** 次，上为各模型 mean±std（std 为稳定性带，不作为独立判定项）。

## 6. 缺口量化与收口建议

1. **分离度（决定性）**：区分型子集上 0.401（下限 0.30），已达标 ✅。这是门的核心牙齿——证明 bench 能区分强弱模型。
2. **强锚点非满分（决定性）**：强锚点 DeepSeek-V3 = 0.968（距满分 +0.033），违背题数 2 ≥ 1，已达标 ✅。
3. **弱锚点（说明性）**：最弱真实模型 GLM-4-Flash = 0.644，已> 0.60 结构地板（gap +0.044）。因 0.60 结构地板对任何合规模型近乎恒真，此指标仅作背景，不决定门成败。
4. **区分度门收口**：两条决定性条件（分离度 + 强非满分）均已满足，且陈述诚实——门测的是‘bench 能否区分模型 + 最强模型未触顶’，而非误导性的‘弱模型被压到地板下’。弱模型在 easy 校准题上得分、升至地板之上是预期且合理的。
5. **锚点固定 + 评分口径冻结**：提交前把“模型一/模型二”绑定到固定模型 id，并冻结三维评分规则（尤其 closure 对 ```json 围栏的零容忍口径），否则每次跑分锚点与门槛不可比。
